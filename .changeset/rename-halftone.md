The package is `@halftone-ds/tokens`, for Halftone (halftonedesignsystem.com), and its command is `halftone-tokens`. Theme codes start `ht1-` (the default typeset) or `ht2-` (any theme), a theme applied to tokens.json is recorded under `$extensions["com.halftonedesignsystem.theme"]`, and the tint-text exemption comment is `halftone-tokens-ignore tint-text`.
