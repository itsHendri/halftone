Components: a component

The group eyebrow, the title and one line. The preview block's header row carries the name, Native | Web (or a "Native only" / "Web only" label) and Preview | Code. Native | Web switches everything under it (Usage, API, Get it, Details), honours ?kit= and is remembered for the next component. Code is the kit's real demo source. A merged entry (Chart, Page header) shows one block per component on the chosen side. Prev and next stay at the bottom.

Studio

Same bar, "Studio" underlined, no back link and no second bar. Same sidebar: the system switcher at the top, then the old tabs as groups. Foundations rows are anchors with a scroll spy; its component-styles section is called Controls so the sidebar never says Components twice. Components is one row (the group chips stay over the canvas). Accessibility shows the pairings below AA. Undo, redo, shuffle, light/dark and Use system sit in a slim toolbar over the canvas.
