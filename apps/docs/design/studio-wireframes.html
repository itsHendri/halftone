The wireframes for /studio, which replaces /themes. The decision record is studio-wireframes.md. Swatches use a sample system ("Acme portfolio": brand seed #1C452E pinned at 800, Newsreader / Manrope / Geist Mono).

1 · Foundations, the whole page

Concept A: one scroll, a sticky section index, every item edited in a popover in place. Each section header has a count, its base knob (Scale, Base radius, Depth) and "+ New". There's no live component rail; the Components tab is one click away. Above the Studio bar, the site nav shrinks to a slim header (not drawn).

2 · Popovers

One shape: a name row (lock and slot tag for fixed slots, an editable name and a trash for extras), then a preview, the values, and a footer for status ("edited · reset", contrast, "used by"). Edits apply live and are undoable, Esc or clicking outside closes, one popover is open at a time, and it opens beside the item and flips at the edge. On a phone it becomes a bottom sheet.

3 · Systems: switcher, new system, first run, shared links

The switcher is the system name in the top bar. Systems are listed newest edit first, each with a 4-colour strip and its name in its own heading font. New starts from a preset, a copy or an import (file, ht- code, shadcn code). There's no blank system: Default is the blank. Migration is silent and one-time. A shared link opens read-only and never overwrites your work.

7 · The Components section of Foundations (Phase 6)

Each variant, or for Input each state, is an item with a role-based colour popover. One theme for both kits: web matches mobile. Tag = Badge. The chip's selected colour is a role, inverted by default.

8 · "+ New", the item menu, and what an extra becomes

Colours asks which kind of colour; every other section copies an item you pick. The new extra lands at the end of its section with the name selected. The token name is the kebab-case version. Right-click (or ⋯) any item to show its usage, copy its class, variable or value, reset it, or duplicate it as an extra. Extras reach tokens.json, CSS, Tailwind and the agent docs.
