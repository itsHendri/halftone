## Or do it yourself

<Tabs items={['New prototype', 'Existing app', 'Monorepo']}>
<Tab value="New prototype">

<Callout type="warn" title="Not yet: copying a single kit">
A kit copied out on its own installs `@itshendri/kit-tokens` from npm, which is not published yet, so
`npm install` fails. Until it is, clone the whole repo (the Monorepo tab) and work in `apps/mobile` or
`apps/web`.
</Callout>

Copy just the kit you need into a new folder and run it. A phone app:

```bash
npx giget@latest gh:itsHendri/protokit/apps/mobile my-prototype
cd my-prototype && npm install
npm run ios    # or: npm run web, npm run dev (Expo Go on a phone)
```

A web app:

```bash
npx giget@latest gh:itsHendri/protokit/apps/web my-prototype
cd my-prototype && npm install
npm run dev    # http://localhost:3100
```

Then rename it, re-brand it and remove the samples: see [Native setup](/docs/mobile) or
[Web setup](/docs/web).

</Tab>
<Tab value="Existing app">

Add kit components one at a time through a [shadcn registry](https://ui.shadcn.com/docs/registry).

**Expo** with [react-native-reusables](https://reactnativereusables.com). In `components.json`:

```json
{
  "registries": {
    "@kit-native": "https://protokit-docs.empty-math-d572.workers.dev/r/native/{name}.json"
  }
}
```

```bash
npx shadcn@latest add @kit-native/theme @kit-native/lib-theme-context
npx shadcn@latest add @kit-native/list-row @kit-native/sheet
npx expo install --fix
```

Wrap the root layout in `<KitThemeProvider>`. Each component page shows its exact command and what it
installs with it.

The kit has refined some react-native-reusables files (Text, Button, Switch and others), and its components
expect those versions. When `shadcn add` asks to overwrite one of them, say yes, or pass `--overwrite`.
Then run `npx expo install --fix`: the registry pins the kit's Expo SDK versions, and this moves them to
yours.

**Next.js** with [shadcn/ui](https://ui.shadcn.com) on Tailwind 4. In `components.json`:

```json
{
  "registries": {
    "@kit": "https://protokit-docs.empty-math-d572.workers.dev/r/web/{name}.json"
  }
}
```

```bash
npx shadcn@latest add @kit/theme
npx shadcn@latest add @kit/data-table @kit/approval-card
```

Components the kit did not change install from shadcn itself (`npx shadcn@latest add dialog`). The kit's
Button, Badge and Slider fix colour contrast that its components rely on: say yes when asked to overwrite
them.

</Tab>
<Tab value="Monorepo">

Clone the whole monorepo for a client project that needs mobile and web on one brand:

```bash
git clone https://github.com/itsHendri/protokit.git
cd protokit && npm install
npm run ios          # the native kit
npm run web:dev      # the web kit, http://localhost:3100
```

`apps/mobile/tokens/tokens.json` is the one brand file. After editing it, `npm run tokens:sync` copies it to
the web kit and rebuilds both themes; CI fails if they differ.

</Tab>
