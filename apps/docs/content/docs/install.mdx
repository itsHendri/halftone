## Or do it yourself

You need Node.js 22.18 or later. Each kit pins the version it's built on in `.nvmrc` (24), so `nvm use` picks it.

<Tabs items={['New prototype', 'Existing app', 'Monorepo']}>
<Tab value="New prototype">

Copy just the kit you need into a new folder and run it. A phone app:

```bash
npx giget@latest gh:itsHendri/halftone/apps/mobile my-prototype
cd my-prototype && npm install
npm run ios    # or: npm run web, npm run dev (Expo Go on a phone)
```

A web app:

```bash
npx giget@latest gh:itsHendri/halftone/apps/web my-prototype
cd my-prototype && npm install
npm run dev    # http://localhost:3100
```

Then rename it, re-brand it and remove the samples: see [Native setup](/docs/mobile) or
[Web setup](/docs/web).

</Tab>
<Tab value="Existing app">

Add kit components one at a time through a [shadcn registry](https://ui.shadcn.com/docs/registry).

**Expo** with [react-native-reusables](https://reactnativereusables.com). In `components.json`:

```json
{
  "registries": {
    "@halftone-native": "https://halftonedesignsystem.com/r/native/{name}.json"
  }
}
```

```bash
npm install -D @halftone-ds/tokens
npx halftone-tokens init        # the kit's tokens, fonts and Tailwind preset, wired into global.css and tailwind.config.js
npx shadcn@latest add @halftone-native/lib-theme-context
npx shadcn@latest add @halftone-native/list-row @halftone-native/sheet
npx expo install --fix
npx halftone-tokens build       # after every add: lib/theme.ts and lib/fonts.ts back to your brand
```

Wrap the root layout in `<KitThemeProvider>` and load the theme's fonts with `useFonts(FONT_ASSETS)` from
`@/lib/fonts`. Each component page shows its exact command and what it installs with it.

The kit has refined some react-native-reusables files (Text, Button, Switch and others), and its components
expect those versions. When `shadcn add` asks to overwrite one of them, say yes, or pass `--overwrite`.
Then run `npx expo install --fix`: the registry pins the kit's Expo SDK versions, and this moves them to
yours.

**Any React app** on Tailwind 4 with [shadcn/ui](https://ui.shadcn.com): Next.js, Vite, React Router or
another, for a prototype or a real product. `components.json` uses Radix and the new-york style (write it rather
than running `shadcn init`; [install.md](/install.md) has the whole file), with the registry:

```json
{
  "registries": {
    "@halftone-web": "https://halftonedesignsystem.com/r/web/{name}.json"
  }
}
```

```bash
npm install tw-animate-css
npm install -D @halftone-ds/tokens
npx halftone-tokens init        # the kit's tokens and fonts, imported into your stylesheet
npx shadcn@latest add @halftone-web/data-table @halftone-web/approval-card
```

Then tell kit components once, at your app's root, how your router links: `<KitLinkProvider link={…}
usePathname={…}>` from `@/lib/link`, with Next.js's or React Router's link (install.md has both). Components
the kit did not change install from shadcn itself (`npx shadcn@latest add accordion`). The kit's Button, Badge
and Slider fix colour contrast that its components rely on: say yes when asked to overwrite them.

Only want the look? Any Halftone theme installs into a shadcn project on its own, colours, radius, shadows and
fonts: `npx shadcn@latest add https://halftonedesignsystem.com/r/theme/editorial.json`, or download your own from
**Use system** in [Studio](/studio). See [Themes](/docs/themes#from-and-to-shadcn).

</Tab>
<Tab value="Monorepo">

Clone the whole monorepo for a client project that needs mobile and web on one brand:

```bash
git clone https://github.com/itsHendri/halftone.git
cd halftone && npm install
npm run ios          # the native kit
npm run web:dev      # the web kit, http://localhost:3100
```

`apps/mobile/tokens/tokens.json` is the one brand file. After editing it, `npm run tokens:sync` copies it to
the web kit and rebuilds both themes; CI fails if they differ.

</Tab>
