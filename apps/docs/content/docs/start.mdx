---
title: Start a prototype
description: Hand your agent a transcript, your notes or a brief. It plans the screens first and waits for your go-ahead.
---

Every kit ships a `transcript-to-prototype` skill. Give your agent what you know about the product, in any shape,
and it turns that into a brief, a screen list and then a working prototype, built only from the kit's components.

## Give it what you know

Any of these works, pasted into the chat or saved as a file:

- **A meeting transcript.** The agent extracts the brief and quotes the transcript for any decision that could be
  argued.
- **Your notes or a feature list.** Rough is fine. Gaps become open questions, each with the default it picked.
- **A brief you wrote.** Use the fields of
  [BRIEF.template.md](https://github.com/itsHendri/halftone/blob/main/apps/mobile/.claude/skills/transcript-to-prototype/BRIEF.template.md)
  as a checklist: who it is for, the jobs, the screens, the key flows, the data, voice and tone, real proof and
  constraints, and what waits for later.

Then say which kit (**phone, web or both**) and, if you have one, give it a **theme code** from [Studio](/studio).

## The prompt

In an empty folder, with your notes beside it as `notes.md` (or pasted in instead):

```text
Read https://halftonedesignsystem.com/install.md and set up the Halftone kit for this project (phone, web or both: <your choice>). Apply theme <code> if I gave one. Then use the transcript-to-prototype skill on notes.md: write the brief and the screen list, and stop for my approval before writing any code.
```

## What the agent does with it

1. **Sets up the kit** from [install.md](/install.md): the mobile kit, the web kit, or both on one brand.
2. **Applies your theme** with the apply-theme skill, if you gave one.
3. **Plans, then stops.** It writes `BRIEF.md` from what you gave it, lists every screen or page with the registry
   components it will use, and the open questions. Then it **waits for your approval** before writing any code.
   Change anything here: it's cheaper than changing screens.
4. **Builds after you approve,** only from registry components, then runs qc-pass and hands over.

The agent never invents proof: no made-up numbers, customers or quotes. Give it the real ones, or leave them out.
